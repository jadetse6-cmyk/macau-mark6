# 澳门六合彩 · 三策略对比模型 v3

基于 1677 期历史数据（2022-2026）的统计预测模型。

## 快速开始

```bash
pip install -r requirements.txt  # 无额外依赖，仅需 Python 3 标准库
python3 macau_model.py
open macau_trend.html
```

## 策略说明

| 策略 | 平码权重 | 特码权重 |
|------|---------|---------|
| 综合Top6 (优化前) | 频14%+漏29%+动24%+加18%+位15% | 频30%+漏50%+近20% |
| 动量Top6 (优化后) | 频15%+漏15%+动45%+轮5%+位10%+加10% | 频30%+漏50%+近20% |
| 并集Top10 (推荐) | 综合∪动量去重 | 综合∪轮转去重 |
